# Code of Conduct

NgBastion adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome newcomers, focus criticism on
ideas and code rather than people, and do not harass anyone in any form. Security research is
welcome; publishing working exploits against third parties is not.

## Enforcement

Report unacceptable behavior privately to the project maintainers (via the repository's private
contact channel; once public, via GitHub's private reporting or a direct message to a maintainer).
Maintainers will review reports confidentially and may warn, temporarily restrict or permanently
remove participants, following the Contributor Covenant enforcement guidelines.
